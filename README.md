# ورشة مشروع تتبع الأجسام والتشفير الفوضوي

Hands-on guide (Arabic, with a short English section) for the FYP
"Object Tracking Using Chaotic Image Encryption with Face Privacy Mode".

Live site: https://0nlymohammed.github.io/Zahraa-fyp-guide/

- `index.html` : the workshop, 9 labs with tested code, real outputs and common errors
- `code/` : every script shown in the guide, plus test video, test photo and YuNet models
- `reference.html` : the longer theoretical reference (Arabic + English)
- `review.html` : review of the proposal form

Static site, no build step. The `gh-pages` branch mirrors `main`.
